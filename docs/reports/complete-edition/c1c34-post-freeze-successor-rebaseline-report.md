## Release gate

`.github/workflows/release-gate.yml` runs on push, pull request and manual dispatch.
It fetches full history, installs with `npm ci`, then requires typecheck, full
regression, build, historical validation, C1C33 freeze and C1C34 rebaseline.
The job has read-only repository permissions. Remote PASS is established by the
actual GitHub workflow result, never by this document's existence.

The full browser production acceptance is retained in the frozen C1C33 evidence.
It is not repeated for this audit-only change; a successor freeze must execute
its own manual/release browser acceptance with real production paths.

## Family selection and successor contract

The matrix compares Prophet, Thing from the stars, Hag and Collector, including
Collector's existing Phase 9D prototype. The planning cost is an explicit project
estimate, not rules authority: unresolved definitions ×2, special components ×2,
save changes ×2, new UI ×2, new battle work ×3, less legacy/shared reuse.

| Family | Planning cost | Main implementation consideration |
| --- | ---: | --- |
| Prophet | 7 | Ruins production primitives and one non-actor Pew mechanism |
| Thing from the stars | 16 | Smaller source set; no existing family runtime |
| Collector | 41 | Prototype exists, but actors, group summons and Loot Chests |
| Hag | 44 | Cauldron/captive Hero plus new battle, UI and save handling |

Decision: `PROPHET_PRODUCTION_BINDING_SELECTED`.
Versioned contract: `C1C34-SUCCESSOR-BINDING-v1`.
Next workstream: **C1C35 — Prophet Official Source Binding & Production Foundation**.

This selects source binding work. It does not authorize execution with missing
dependencies: `foundationExecutionAllowed=false`, executable paths 0,
`productionReady=false`. The five explicit blockers are Tile, d10 mapping,
Crowded ties, per-Pew order/save, and target/effect glyph binding. The nine
production paths each list required source fields, shared primitives and required
acceptance. The contract requires source/ruling closure before execution and
normal selector, all-level real combat, save/replay, tamper rejection and browser
proof before promotion. No new Boss framework or prototype value is adopted.
