# 11A.5-C2C — Hero production definition layer

C2C introduces an isolated, source-backed candidate layer for all 18 official
Heroes: 54 logical Profiles, 126 Skill identities and 378 independently printed
Skill Level definitions, representing all 432 frozen C2B forms.

The baseline is `84e747b170d4ba65c463d1d5be1cfcd80dd0dd08`. Production release
gate run [37129945901](https://github.com/Alpaca-go/darkest-dungeon-boardgame/actions/runs/37129945901)
completed successfully for that exact SHA before C2C began. It is an accepted
historical checkpoint with its original `HERO_LITERAL_CLOSURE_BLOCKED` source
outcome. No C2B-R1 was created, and no official conflict was canonically resolved.

`SOURCE_AMBIGUITY_DEFER_POLICY_V1` is the forward policy. Eight shared executable
gap groups are deferred for manual validation: Crusader Preparation Days, Self
movement order, condition-transfer stacks, Transform atomic ordering, Flagellant
conditional connective, modifier phase, serialization and legacy save identities.
Both original conflict sources remain bound. Deferred subfields are noncanonical,
have null execution bindings and do not block independent clear behavior.
Illustrative pictograms remain official printed artwork without executable meaning.
The root `AGENTS.md` remains unchanged because it is itself frozen C1C30 evidence;
the versioned policy artifact and C2C successor decisions carry the forward policy.

The candidate TypeScript modules preserve printed absence, both Abomination
Profile variants, both Transform actions, separate Self/Target collections,
multi-target and all-target scopes, movement alternatives, condition magnitude and
duration, distinct Guard/Protection ignores, conditional/type damage modifiers and
Hamlet choices, roll outcomes and delayed operations. Definitions and nested values
are frozen. Each level is derived from its own source row rather than a progression
formula. Compact immutable source bindings point to full provenance in audit data.
Accuracy rolls remain separate from damage attacks: healing, control and support
skills do not gain an attack block when printed Damage is absent.

The migration map covers all eight current Hero IDs, 24 current Profile levels and
28 current prototype Skills. Twelve unmatched Skills are marked
`REMOVE_ON_C2D_MIGRATION`, including Bash. Printed identity matches do not validate
prototype values. The Dodge migration map covers every official Hero level while
keeping `C1C31-DIGITAL-DEFAULT-v2` live and unchanged.

The C2C boundary verifier compares every existing non-audit source file to the C2B
baseline, checks the frozen C2A/C2A-R1/C2B corpus, rejects candidate imports by live
entrypoints and limits new non-audit files to the isolated definitions and schema.
The existing C2A-R1 and C2B source auditors and tests are unchanged. Their original
phase-specific boundaries and adversarial suites run in their accepted detached
checkouts through a successor audit test, following the repository's existing
historical-suite pattern. Historical verification preserves the original C2B
outcome; the new C2C verifier checks the candidate boundary independently.

Validation evidence is stored in `c2c-validation/validation-results.json` and its
command logs. `verify:complete-edition-c2c` recomputes counts from TypeScript
definitions, compares every generated artifact with the frozen source conversion,
validates actual source hashes, and checks live isolation. Adversarial cases reject
source drift, formula progression, flattened forms, numeric defaults, fixed all-ally
counts, lost ignore-defense effects, canonical deferred behavior and dropped gaps.
The final local full suite passed 2,855 tests across 183 files, with zero failed,
pending or todo tests. It includes 31 C2C candidate tests and two historical suite
wrappers; those wrappers additionally execute the unchanged 20 C2A-R1 and 26 C2B
assertions at their accepted checkpoints. Typecheck and production build passed.
Earlier failed attempts and their repairs remain in the validation evidence.
All 16 requested local validation commands completed successfully. A historical
Guardian mutation subprocess timed out on one attempt; the complete immutable
baseline retry passed, including all 2,729 original C1C35R2B-R1 tests. The final
isolation proof covers 807 unchanged live source files and 1,359 frozen evidence
files. Successor compatibility and the built-bundle smoke test also passed.

The data-layer acceptance is `HERO_PRODUCTION_DEFINITION_LAYER_ACCEPTED`.
Final release acceptance additionally requires a successful Production release gate
for the final C2C SHA. C2D is the next workstream after that gate; it has not begun.
Live gameplay, selectors and saves remain on the existing prototype path. Thing
remains `SOURCE_ACQUISITION_HOLD`.
